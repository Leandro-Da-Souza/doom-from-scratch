# Doom From Scratch

This project is a personal learning exercise: recreating the original **DOOM** from scratch with the help of AI in order to better understand game development and get introduced to programming in **C**.

The goal is not to build a perfect copy, but to explore the ideas behind classic game engines step by step. Through this project, I want to learn how things like rendering, movement, maps, input, collisions, and game loops work at a lower level, while also becoming more comfortable with C as a language.

DOOM is an important piece of game development history, and rebuilding parts of it is a fun way to study the concepts that made early 3D games possible.
The original DOOM source code is open and available at <https://github.com/id-software/doom>

This repository will grow as I experiment, make mistakes, and learn more about how games are built from the ground up.
